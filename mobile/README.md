# MGA Mobile (Expo / React Native / TypeScript)

Application mobile MGA, cf. `../ARCHITECTURE.md`.

## Installation

```bash
cd mobile
npm install
cp .env.example .env
npx expo start
```

Sprint 1 livre : login, dashboard (structure), liste clients, fiche
client, catalogue produits. Voir ARCHITECTURE.md pour le plan des sprints
suivants (devis, factures, offline, assistant IA, dimensionnement solaire).
